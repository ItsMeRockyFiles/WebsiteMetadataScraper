🚀 How to Publish on RapidAPI Hub

This API is fully structured for simple monetization on RapidAPI:

  1. Deploy: Host this Node.js repository on Render, Railway, or Vercel.
  2. Create RapidAPI Listing: Add target base URL https://your-app.onrender.com/api/v1.
  3. Set Proxy Secret: Add RAPIDAPI_PROXY_SECRET in your .env on Render to reject requests that bypass RapidAPI.
  4. Define Endpoint: GET /scrape?url={url} with parameter url (String, Required).
